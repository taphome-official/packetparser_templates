# Meteosource API

Purpose: this template provides weather information based on Meteosource API (https://www.meteosource.com/). To use it, sign up for free to get an API key at https://www.meteosource.com/client/sign-up .

## Settings
- API key
- longitude
- latitude
- time-zone

## Parameters
Currently implemented weather parameters:
- current temperature
- type of weather (sunny, cloudy, ...)
- max. daily temperature
- min. daily temperature
- 1-hour precipitation
- daily precipitation
- wind speed
- wind direction

## Optional
You can obtain additional set of weather parameters by upgrading your free account. More details at https://www.meteosource.com/
